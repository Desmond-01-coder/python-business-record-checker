# Python Business Record Checker

## About the Project

The Python Business Record Checker is a beginner-friendly inventory management program built with Python. It helps small businesses keep track of their products, monitor stock levels, calculate inventory value, and update quantities.

This project was created to develop practical Python programming and problem-solving skills.

## Features

* Displays product names, prices, and available quantities.
* Calculates total inventory value and summary statistics.
* Identifies products with low stock or no stock.
* Searches for products by name.
* Supports stock-in and stock-out operations.
* Validates user input to prevent invalid quantities and insufficient-stock errors.
* Saves and loads inventory data using JSON, so changes persist after restarting the program.

## Technologies Used

* Python
* JSON

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

   ```bash
   python main.py
   ```

## Project Files

* `main.py` — Contains the Python program and inventory management logic.
* `inventory.json` — Stores inventory data between program sessions.
